# TWO RULES THAT WILL BREAK YOUR INSTALL IF YOU IGNORE THEM
# ---------------------------------------------------------------------------
#
# 1. Use Python 3.12. Do NOT use 3.14.
#    Gymnasium's `box2d` extra resolves differently per interpreter:
#       python < 3.14  ->  box2d == 2.3.10     (prebuilt wheel, no compiler)
#       python >= 3.14 ->  box2d-py == 2.3.8   (SOURCE ONLY: needs SWIG + MSVC)
#    On a machine without a full C++ toolchain, the 3.14 path fails outright.
#
# 2. The pinned CUDA variant comes from the PyTorch index. PyPI also has an
#    unqualified Windows CPython 3.12 torch 2.14.1 wheel; this file pins cu130.
#    The `--extra-index-url` line below is needed for the +cu130 build.
#    The `cu130` build matches a CUDA 13.x driver. On an older driver, change
#    `cu130` here (and in the README) to an available matching build such as
#    `cu126`, or use requirements-cpu.txt. cu128 did not list 2.14.1 cp312.
#
# ---------------------------------------------------------------------------
